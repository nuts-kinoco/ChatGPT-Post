# 常駐表示とテーマの使い方・検証

採用されたA案は常駐バー440×46px、展開時はヘッダーを含む全体440×604pxです。同じ幅で下方向へ展開し、画面を切り替えても外枠寸法は同一です。小さい表示領域では領域内へclampします。実際のWindows描画・倍率・OS動作は別途検証が必要です。

これは表示設定の中間実装です。TaskSpec/ResultSpec、承認、実行、成果物、受領確認の意味を変えません。実チャット＋CLI往復の完了証明ではありません。

## 起動と戻り方

ルートで `npm run build`、続いて `gui/` で `npm run build` / `npm start`。portable版も更新後に再ビルドします。起動直後は最大440×46pxの常駐バーです。右端の「↗」を押すと同じウィンドウ内で下へ展開します。既定ページは「状況・結果」です。LLMがBridge CLIから発行・保存した依頼を確認する使い方が中心で、手動JSON/MD取り込みは補助操作です。

- 「⌃」: 詳細画面を読み込み直さず、バーへ戻る。入力・選択・処理を保持
- 「最小化」/閉じる操作: 設定に従い、バーへ戻るかトレイへ隠す
- トレイの「Bridge v2 を表示」/左クリック: 隠す前の表示へ戻る
- トレイの「常駐バーへ畳む」: 明示的に小さい表示へ戻る
- `Ctrl+Shift+C`: 表示/非表示を切り替える。別アプリが使用中なら登録できない場合がある
- トレイの「終了」: アプリを終了。閉じる/隠すとは別

依頼の状態変化や完了通知で、勝手に展開・フォーカス・サイズ変更をしません。既存の詳細画面へ戻るときは、その画面の選択と未送信入力を維持します。別の依頼は一覧で選びます。

## 表示設定

歯車または「表示設定」を開きます。保存した設定は次の起動でも適用します。

- ライト/ダーク: 常駐バー、詳細、フォーム、状態色に共通適用
- 最前面に表示: デスクトップの製品ウィンドウに適用
- 非アクティブで隠す: 別アプリへ移ったときに隠す。トレイ/ショートカットから復帰
- 最小化でトレイへ隠す: OFFはバーへ戻る、ONは隠す
- 画面内の完了通知: 常駐バーは「結果 N」を表示し、展開画面は通知を表示。勝手に展開せず、通知上からも1クリックでOFF。結果と履歴は残る

ブラウザ版 `npm run ui` でもテーマと画面内通知を使えます。最前面・非アクティブ・トレイはElectron専用で、非対応画面では理由を示して無効です。ブラウザの「最小化」はバーへ畳む操作です。

OS通知権限は要求せず、Email/Discord/ペットへ送信しません。外部通知の設定・許可・テスト送信は後続の別機能です。

## 保存・安全性

- 表示設定だけを `CHATGPT_BRIDGE_RUNTIME_DIR/presentation.db` に保存。タスク台帳・プロジェクト登録・実行権限とは別
- `bridge-presentation-1` とrevisionを持つ。別画面で変更済みなら古い保存を拒否し再読込を求める
- localStorageに保存するのはテーマ名だけ。依頼・出力先・通知先・権限・秘密情報は保存しない。従来の起動用capabilityは同じタブのsessionStorageにだけ保持
- 設定保存は開始、承認、成果物移動、外部通知送信を起こさない
- native preloadは表示状態と6種類のウィンドウ操作だけ。旧GUIのファイル/CLI APIを公開しない
- IPCは対象製品ウィンドウと正しいloopbackページだけを受け付け、任意のコマンド/パス/URLを受け付けない

## 検証手順

固定コミットを確認し、ルートとguiでtypecheck/lint/build/testを実施します。ブラウザスキップは成功に数えません。

1. 起動後は小さなバー。依頼が開始/完了しても自動展開しない
2. 展開して未送信JSON/MDを入力 → 入力画面の「⌃」 → 隠す → 復帰。入力画面、入力内容と選択UUIDが同じ。長文でも外枠は440×604pxのまま、内部だけスクロール
3. 遅い画面準備中に隠す。遅れて完了した展開が新しい操作を取り消さない
4. ダークへ変更。ドック/詳細/フォーム/状態色へ反映し再起動後も維持
5. 別画面から古いrevisionで保存。上書きせず再読込を要求
6. 最前面、非アクティブで隠す、最小化先を切替。必ずトレイから戻れる
7. 完了通知OFF後も結果・イベント・ACKが同じ。ONに戻して古い結果を再通知しない
8. 狭い画面、100/125/150/200%表示、モニター取り外しで到達不能にならない
9. API認証なし/別Origin/未知項目/secret・task・path追加/古いrevisionを拒否

NodeのHTTP/SQLite/DOMハーネスと表示状態の単体試験は、実際のWindows描画・OS動作試験と別です。既知のブラウザアクセス制限を迂回せず、描画成功とは扱いません。
