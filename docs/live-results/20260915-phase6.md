## 確定した事実

### 画像生成の受け取り（MM-02、A-091 / A-092）
- 回答ターンの画像は `img[alt^="生成された画像"]`、同一 `src`（`https://chatgpt.com/backend-api/estuary/content?id=…&sig=…`）が 3 要素に描画される。naturalWidth 1536
- ターンの「その他のアクション」メニュー（ソースを表示 / 新しい分岐を開く / 音声で読み上げる）にダウンロードは無い。画像クリックで開くビューア（role=dialog）に「保存」がある（他に マークアップ / コメント / 背景を削除 / 消去 / リサイズ / 共有 と、**ビューア独自の入力欄と送信ボタン**）
- **ビューア「保存」のダウンロード開始で Chrome stable がクラッシュ**（3 回中 2 回、`runtime/profile/Crashpad/reports` にダンプ）。ブリッジ実行では `BROWSER_CRASHED`（画像自体は保存済み）
- ページ内 `fetch(img.src)`（credentials include）は 52 ms で同一バイト列（923,014 B）。これを主経路にし、ビューア経由は環境変数で opt-in
- 画像のみのターンは本文が無く、innerText は「編集」ボタンのラベルだけになる → 画像があれば `markdown: ""` で成功扱い
- クラッシュ後に同じ requestId を再実行すると `SUBMIT_STATE_UNKNOWN`（マーカー残存。設計どおり）
