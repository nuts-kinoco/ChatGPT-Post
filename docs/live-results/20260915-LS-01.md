## 実画面で確定した事項（OQ-002 / OQ-003 / OQ-009）

- モデル / effort の選択 UI は入力欄右側の「思考量」メニュー: 思考 effort は 5 段階スライダー（`[data-model-reasoning-effort-slider] [role=slider]`、`aria-valuemin=0 aria-valuemax=4`。現在 3 = 「極高」）、モデルはラジオ（「最新」= 既定、「GPT-5.6 Sol」、「GPT-5.5」）。preset 列挙は effort の 5 段階に対応する。段階 3 = `extra_high` のみラベル確定、他は Phase 5 の選択実装時に確定。
- 「回答をコピーする」（`data-testid="copy-turn-action-button"`）は `navigator.clipboard.writeText` で **Markdown**（```typescript フェンス付き）を書く。ページ内フックで捕捉でき、システムクリップボードは不要（OQ-003 解決）。
- 未ログイン画面にも入力欄があるため、ログイン判定は「ログイン導線が見えれば `AUTH_REQUIRED`」（A-056）。
- Google ログインは自動操作中の Chrome を拒否する。初回ログインは通常の Chrome を専用プロファイルで起動して人間が行う（A-055）。
- 送信直後の URL は一時 ID `/c/WEB:…` で、数秒後に本 ID `/c/<uuid>` に置き換わる。
- 新規チャットはサイドバーのリンクが複数あるため URL 遷移（`https://chatgpt.com/`）で開く。
